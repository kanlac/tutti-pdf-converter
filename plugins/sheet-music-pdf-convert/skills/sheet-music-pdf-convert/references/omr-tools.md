# Other ways to read a score

For when neither Tutti nor Audiveris fits. Prices, platforms and features change: confirm on the official site before recommending, and never buy or install anything for the user without asking. Listed facts were last checked 2026-11.

| Tool | Reads | Where it runs | Notes |
|---|---|---|---|
| PlayScore 2 — https://www.playscore.co/ | Photos and PDFs of printed music | Phone / tablet app | Quick for photos taken on the device |
| ScanScore — https://scan-score.com/ | Scans and photos of printed music | Desktop app | Exports MusicXML |
| SmartScore — https://www.musitek.com/ | Scans of printed music | Desktop app | Long-standing commercial OMR |
| PhotoScore — https://www.neuratron.com/photoscore.htm | Scans and PDFs | Desktop app | Often paired with Sibelius |
| Soundslice scanner — https://www.soundslice.com/sheet-music-scanner/ | Photos and PDFs | Web | Result opens in Soundslice's editor |
| PDFtoMusic Pro — https://www.myriad-online.com/en/products/pdftomusicpro.htm | Only PDFs exported from notation software (not scans) | Desktop app | Reads the PDF's vector data, like Tutti |

## Picking one from what went wrong

- **Audiveris left most of a clear scan unread**: a commercial scan tool (ScanScore, SmartScore, PhotoScore) is the next step.
- **It's a phone photo and retaking isn't possible**: PlayScore 2 or the Soundslice scanner are made for photos.
- **The PDF came from notation software but Tutti doesn't support it yet**: PDFtoMusic Pro reads the same kind of PDF.
- **Handwritten music**: no tool reads it reliably; re-entering it in a notation program is usually faster than correcting OMR output.
- **The user cannot install software** (managed computer): web options (Tutti, Soundslice) are the only ones that need no installation.
