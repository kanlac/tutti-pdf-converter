# Other ways to read a score

For when neither Tutti nor Audiveris fits. Prices, editions and platforms change: confirm on the official site before recommending, and never buy, install or upload anything for the user without asking. Facts below were checked on the official sites on 2026-11-08; vendors' accuracy claims are not verified.

| Tool | Reads | Where it runs | Notes |
|---|---|---|---|
| PlayScore 2 — https://www.playscore.co/ | Photos, images and PDFs of printed music | iOS / Android apps; Windows desktop app | MusicXML export needs a subscription. Its FAQ limits generated MIDI / MusicXML to non-commercial use; professionals should check the terms first |
| ScanScore — https://scan-score.com/ | Scans, phone photos, PDFs and images of printed music | Windows / macOS desktop (phone as a capture device) | Editions differ in how many staves they handle; the trial limits export |
| SmartScore 64 — https://www.musitek.com/ | Scans, TIFF and PDFs of printed music | Windows / macOS desktop | The MIDI Edition does not export MusicXML; other editions do |
| PhotoScore & NotateMe — https://www.neuratron.com/photoscore.htm | Scans and PDFs; the Ultimate edition also claims handwriting recognition | Windows / macOS desktop | Official system requirements list older systems; current Apple-silicon support is not confirmed |
| Soundslice scanner — https://www.soundslice.com/sheet-music-scanner/ | Photos and PDFs | Web service (the file is uploaded) | Result opens in Soundslice's editor; exports MusicXML |
| PDFtoMusic Pro — https://www.myriad-online.com/en/products/pdftomusicpro.htm | Only PDFs exported from notation software, not scans | Windows / macOS / Linux desktop | Reads the PDF's vector data |

## Picking one from what went wrong

- **Audiveris left most of a clear scan unread**: a desktop scan tool (ScanScore, SmartScore, PhotoScore).
- **It's a phone photo and retaking isn't possible**: PlayScore 2 or the Soundslice scanner, which are made for photos.
- **The PDF came from notation software but Tutti declines it**: PDFtoMusic Pro reads the same kind of PDF; results will differ from Tutti's.
- **Handwritten music**: PhotoScore & NotateMe Ultimate says it reads handwriting; suggest a trial on one page first, with no promise. Re-entering by hand is the dependable fallback.
- **The user cannot install software** (managed computer): only the web options (Tutti, Soundslice) need no installation, and both upload the file.
